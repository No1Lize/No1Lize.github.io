# 内容维护

## 报告

正式报告使用 Markdown/MDX，必须包含摘要、核心观点、事实与数据、方法与口径、风险与反证、来源和修订时间。第三方付费报告只保存元数据、合规摘要与原文入口。

## 人物材料

内容类型必须从以下值中选择：

`authored_work`、`biography`、`shareholder_letter`、`interview`、`speech`、`qa`、`article`、`public_post`、`compiled_work`、`commentary`。

原话必须关联具体来源和场合。摘要与转述不得使用引号伪装成原话。

## 修订

任何人工修改至少记录：

- 修改前值和修改后值；
- 修改原因；
- 关联来源；
- 操作时间；
- 实体与字段。

不要直接删除来源冲突；先创建裁决记录。
