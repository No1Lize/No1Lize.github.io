# 运维

## 任务频率

- 快讯与融资：2 小时；
- 公司与机构官网：6 小时；
- SEC、IPO、公告和财报：每日；
- 人物材料：每日；
- HeatScore：每日；
- 摘要：每周或重大事件触发。

## 失败处理

采集请求最多重试三次并指数退避。单个 Adapter 失败不会中止其他来源；连续失败应暂停来源并保留最后成功数据。日志不得记录 Secret、数据库口令或完整授权头。

## 观察指标

每次任务记录开始/结束、状态、扫描、新增、更新、跳过、冲突和错误数。公开状态页只显示总体新鲜度，不暴露内部错误上下文。

## 备份

Neon 自动备份之外，每周导出结构与关键表；每季度执行一次恢复演练。公开快照不是数据库备份。
