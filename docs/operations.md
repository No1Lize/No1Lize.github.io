# 运维

## 任务频率

- GitHub Actions 每两小时检查 OpenAI 与 SEC；
- 无新增或修订时不提交；
- 可从 Actions 页面手动选择 `all`、`openai` 或 `sec` 运行。

## 失败处理

单个来源失败时保留仓库中的最后成功数据；若所有选定来源均失败，任务以失败状态结束并保留原 JSON。任务不访问登录页面、不绕过访问限制，也不记录授权信息。

## 观察指标

Actions 日志显示来源、抓取数量、总记录数和错误摘要。公开页面只显示 JSON 生成时间，不暴露任务内部错误。

## 恢复

`articles.json` 的每次变化都保存在 Git 历史中。误抓取时可回退对应数据提交；Pages 构建失败不会替换上一版站点。
