# 数据来源

## 已接入

| 来源族 | 方式 | 前端等级 | 用途 |
|---|---|---|---|
| OpenAI、Anthropic、Figure、xAI 等公司官网 | 公开 HTML | 官方披露 | 产品、融资、合作与公司进展 |
| Pony.ai、WeRide、Rocket Lab 等 IR 页面 | 公开 HTML | 官方披露 | 公司公告与经营进展 |
| SEC EDGAR submissions / Company Facts | 公开 JSON | 监管文件 | 申报、财报和带期间的财务指标 |
| TechCrunch、VentureBeat、钛媒体、雷峰网 | RSS | 媒体报道 | 创投、产品和产业动态 |
| 新浪财经 | 公开滚动 JSON | 媒体报道 | 中国金融、上市与科技产业动态 |
| Google DeepMind、Google AI | RSS | 官方披露 | 官方研究和产品动态 |
| X 机构与人物公开资料 | 公开 syndication 页面 | 原始材料 | 公司动态和人物公开观点 |
| OpenAlex | 公开 API | 数据库记录 | 论文元数据 |
| arXiv | Atom | 原始材料 | 开放论文元数据与原文链接 |
| 微信公众号公开索引 | Bing RSS + 严格目标域名校验 | 待交叉验证 | 仅发现 `mp.weixin.qq.com` 的公开结果 |
| 金融媒体公开索引 | Bing RSS + 严格目标域名白名单 | 媒体报道 | 补充公开可访问的金融和创投报道 |
| 今日头条公开索引 | Bing RSS + `site:toutiao.com` 域名白名单 | 媒体报道 | 每个启用赛道一路，按赛道关键词、公司与人物发现公开报道 |
| 鲸准、企查查 | 页面外部检索入口链接（不抓取） | — | 公司与人物页提供工商、股权与创投数据的对方平台直达检索 |

配置以 `config/intelligence_sources.json` 为准。X、微信和媒体只保存元数据、短摘要和原始链接，不保存全文。鲸准与企查查是商业数据库，本站只生成检索入口链接，不请求、不缓存其任何数据。

## 质量和冲突

- 日期必须是可解析的真实日历日期，明显未来日期被拒绝；
- 只出现 NASDAQ/NYSE 字样不会被误判为 IPO；
- 同一规范化 URL 只保留一条，第二层再按主体、日期和标题指纹去重；
- 人工标记 `curated` 的标题与摘要优先；
- 成功来源只替换自己的历史批次，失败或空来源保留上一版；
- 不同来源的独立记录不互相覆盖，详情仍链接原始页面；
- 单一来源占比过高或地区、平台、类型不足时拒绝覆盖快照。

## 尚未接入

- Crunchbase、IT 桔子、企名片、Wind、鲸准、企查查的数据抓取：需要商业授权或 API Key（鲸准、企查查目前仅以页面入口链接形式接入）；
- 需要登录、验证码、付费订阅或禁止自动访问的内容；
- 微信站内私域数据、朋友圈和非公开文章；
- X 登录后才能查看的内容。

无授权时不伪造 Adapter、接口响应、融资金额、估值或人物引语。
