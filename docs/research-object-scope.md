# 四类核心研究对象与证据层

## 产品边界

VCIQ 的公开研究主线只包含四类对象：

1. **核心技术**：具体技术、技术系统、工程能力或技术产品，不包括宽泛产业分类。
2. **核心赛道**：用于组织产业结构、长期变量、公司样本和研究问题的领域级分类。
3. **核心人物**：与核心技术、赛道或公司直接相关的创始人、科学家、工程负责人、产品领导者和关键决策者。
4. **核心公司**：一级市场科技公司及其技术、产品、团队、融资、商业化和生命周期证据。

主导航、首页研究概览、对象更新流和全局搜索均应优先围绕这四类对象组织。

## 辅助证据层

以下内容继续保留，但不再作为独立的一级研究对象或主导航频道：

- 投资机构与资本关系；
- 研究报告与 PDF 原文；
- 融资、并购、IPO、财报和监管披露；
- 已上市公司的行情、公告和退出表现；
- Research Agent 的变化检测结果；
- 收藏、搜索和追踪证据图谱。

辅助层的职责是回答“这一判断由什么证据支持”，而不是与四类核心对象并列争夺产品主线。

## 上市跟踪退役规则

- 不生成 `/ipo` 目录页或 `/ipo/[slug]` 详情页；
- 主导航、首页频道流和 sitemap 不出现“上市跟踪”；
- 旧收藏中的 `ipo` 类型自动迁移为“核心公司”，并将可映射路径改为 `/companies/[slug]`；
- 上市、并购、退出、财报和监管披露仍可进入公司档案的生命周期时间线；
- 构建后工件审计拒绝任何 `/ipo` 静态路由重新出现。

## 技术与赛道的分层

- 赛道目录来源于启用的追踪配置，例如 AI、机器人、半导体等领域分类；
- 技术目录来源于已经达到公开门槛的具体 `topic` 实体；
- 当技术实体名称或别名与赛道名称完全一致时，保留在赛道层，避免重复建立技术卡片；
- 技术实体必须具有公开动态、人工发现、关注等级、研究记录、研究判断或分析笔记之一，才可进入公开目录。

## 发布门禁

公开构建必须满足：

- 人工采集实体已经完成最终身份解析；
- 研究对象具有实质性证据或分析内容；
- 追踪覆盖完整，且构建过程不修改数据输入；
- 构建来源 Git SHA 可追溯；
- 最终工件不包含审核后台、写入控件、`/ipo` 路由或退役频道文案。

## 后续数据管线建议

当前公开页面已经按四类对象收敛。后续数据层应逐步完成：

1. Research Agent 将机构、上市市场和监管披露明确标记为辅助证据，并把结论归因到四类对象；
2. 建立统一 `research_object_id`，让事件、报告、机构关系和市场披露都指向一个或多个核心对象；
3. 为技术与赛道建立明确的 `technology -> track` 从属关系，避免关键词自动升级为公开技术对象；
4. 对长期不再服务四类对象的数据任务进行使用量审计，再决定停用，而不是直接删除仍被公司证据链引用的抓取能力。
