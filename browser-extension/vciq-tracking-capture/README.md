# VCIQ 研究采集浏览器扩展

该扩展只负责把当前公开网页的标题、URL 和用户主动选中的文字带到：

`https://vciq.github.io/tracking/capture/`

扩展本身不读取或保存 GitHub Token，也不会自动提交追踪配置。

## 安装

1. 解压下载的扩展包。
2. 在 Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的目录。

## 使用

- 采集整篇网页：点击扩展图标，或在网页空白处右键选择“采集当前网页到 VCIQ”。
- 采集公司：选中公司名称，右键选择“将选中文字作为公司追踪”。
- 采集人物：选中人物名称，右键选择“将选中文字作为人物追踪”。
- 采集技术主题：选中文字，右键选择“将选中文字作为技术／主题追踪”。

进入 VCIQ 后仍需核对实体类型、名称、目标赛道、研究原因和来源上下文，再由管理员提交。

## 权限边界

- `contextMenus`：创建右键菜单。
- `activeTab`：仅在用户主动点击扩展或菜单时读取当前标签页标题和 URL。
- 无主机权限。
- 无后台抓取。
- 无 GitHub Token 权限。
