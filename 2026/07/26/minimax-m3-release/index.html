为什么重要：

M3 是首个同时在编程、智能体和长上下文三项能力上达到前沿水平的国产模型，MSA 架构若验证有效，将改变国产大模型的技术路线竞争格局。

核心信息

MiniMax 于 7 月 26 日正式发布 M3 大语言模型。该模型基于自研 MSA（Multi-Scale Attention）架构，具备以下关键能力：

  • 1M 超长上下文：原生支持百万级 token 输入，无需外挂 RAG
  • 原生多模态理解：文本、图像、视频统一处理
  • 编程与智能体双优：在 SWE-bench、AgentBench 等基准上达到前沿水平

为什么重要

过去国产大模型往往在某一项能力上突出（如代码或推理），但 M3 是首个三项兼备 的国产旗舰。如果 MSA 架构被验证可扩展，意味着国产模型在底层架构创新上不再只是追赶，而是开始定义路线。

定价与可用性

  • API 定价定在国产模型高端区间
  • 开源权重计划于 Q3 发布
  • 已上线 MiniMax Platform 控制台

行业反应

瑞银证券分析师指出，Kimi K3 和 MiniMax M3 的密集发布，说明中国模型厂商已从”追赶差距”进入”定义溢价”阶段。
